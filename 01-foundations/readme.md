
# Phase 1: Computer and OS Fundamentals

<sub>Duration: Weeks 1–2</sub>

## Overview

Understand how computers work internally, how operating systems manage resources, and how hardware and OS-level decisions affect application performance, concurrency, and scalability.

---

## Topics Covered

### 1. Computer Architecture and Hardware
- CPU architecture
- Cache hierarchy (L1, L2, L3)
- Memory and disk
- Latency numbers every programmer should know
- HDD vs SSD vs NVMe vs RAM: performance and cost

### 2. Processes and Threads
- Processes and threads
- Context switching
- CPU scheduling
- Process and thread lifecycle

### 3. Concurrency Fundamentals
- Locks and mutexes
- Semaphores
- Deadlocks
- Race conditions
- Atomic operations

### 4. I/O Models
- Blocking and non-blocking I/O
- Asynchronous I/O
- epoll
- io_uring
- Event loops

### 5. Memory Management
- Virtual memory
- Paging
- Page cache
- Memory-mapped files
- Zero-copy

### 6. File Systems and Durability
- File systems
- fsync
- Disk persistence
- What durability really means

### 7. Container Fundamentals
- Containers
- cgroups
- Namespaces
- Resource isolation

### 8. Hardware-Level Performance
- NUMA architecture
- Hardware effects on application performance
