
# Phase 2: Networking

<sub>Duration: Weeks 3–4</sub>

## Overview

Understand how computers communicate over networks, how data travels between clients and servers, and how modern networking protocols enable reliable, secure, and scalable communication in distributed systems.

---

## Topics Covered

### 1. Networking Fundamentals
- Network architecture and fundamentals
- OSI model
- TCP/IP model
- IP addressing (IPv4 and IPv6)
- MAC addresses
- Subnets and CIDR
- Public vs private IP addresses
- Ports and sockets

### 2. Transport Layer: TCP and UDP
- TCP fundamentals
- TCP three-way handshake
- TCP connection termination
- TCP reliability and retransmission
- Flow control and congestion control
- Sliding window protocol
- UDP fundamentals
- TCP vs UDP
- When to use TCP and UDP

### 3. DNS (Domain Name System)
- DNS fundamentals and hierarchy
- DNS resolution process
- Recursive vs iterative queries
- DNS records: A, AAAA, CNAME, MX, TXT, NS
- DNS caching and TTL
- DNS propagation
- DNS load balancing
- DNS-based routing

### 4. HTTP and Web Protocols
- HTTP fundamentals
- HTTP request and response lifecycle
- HTTP methods and status codes
- HTTP headers
- HTTP/1.1
- HTTP/2: multiplexing, streams and binary framing
- HTTP/3 and QUIC
- Persistent connections and keep-alive
- Cookies and sessions
- Stateless vs stateful communication

### 5. TLS and Secure Communication
- Encryption fundamentals
- Symmetric vs asymmetric encryption
- Public and private keys
- TLS handshake
- SSL vs TLS
- Digital certificates
- Certificate Authorities (CA)
- HTTPS
- Mutual TLS (mTLS)
- Certificate validation and expiration

### 6. Load Balancers
- Load balancing fundamentals
- Layer 4 vs Layer 7 load balancing
- Round Robin
- Weighted Round Robin
- Least Connections
- IP Hash
- Consistent Hashing
- Health checks
- Session persistence (sticky sessions)
- Active-active and active-passive configurations

### 7. Proxies
- Forward proxy
- Reverse proxy
- Transparent proxy
- Proxy vs load balancer
- API Gateway
- Reverse proxy use cases
- Connection pooling
- Request routing
- Proxy caching

### 8. Content Delivery Networks (CDN)
- CDN fundamentals
- Edge locations and Points of Presence (PoPs)
- Origin servers
- Cache hit and cache miss
- Cache-control headers
- CDN cache invalidation
- Pull vs push CDN
- Static vs dynamic content delivery
- Geographic routing
- CDN security and DDoS protection
